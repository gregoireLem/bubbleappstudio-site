# Deployment

This site is deployed to GitHub Pages from the `main` branch.

Repository:

```sh
/Users/gregoirelemoulant/Documents/Perso/bubbleappstudio-site
```

Production URL:

```text
https://www.bubbleappstudio.xyz/
```

## Normal deploy

Run this from the site repo:

```sh
cd "/Users/gregoirelemoulant/Documents/Perso/bubbleappstudio-site"
npm run build
git status --short
git add <files-to-deploy>
git commit -m "<clear commit message>"
git push origin main
```

Pushing to `main` triggers the GitHub Actions workflow:

```text
.github/workflows/deploy.yml
```

The workflow runs:

```sh
npm ci
npm run build
```

Then it uploads `./dist` to GitHub Pages.

## Verify the deploy

After pushing, check the target route with:

```sh
curl -L -I https://www.bubbleappstudio.xyz/<route>/
```

Expected result:

```text
HTTP/2 200
```

For the Password game : duel TikTok redirect:

```sh
curl -L -I https://www.bubbleappstudio.xyz/password-game/tiktok/
```

## Manual fallback

If the push succeeds but the deploy does not start, open:

```text
https://github.com/gregoireLem/bubbleappstudio-site/actions/workflows/deploy.yml
```

Then:

1. Click `Run workflow`
2. Select branch `main`
3. Run it
4. Wait for the workflow to finish green
5. Re-check the route with `curl -L -I`

## Updating the TikTok CTA target

The app CTA should point to the stable site redirect, not directly to TikTok:

```text
https://www.bubbleappstudio.xyz/password-game/tiktok/
```

To change the final TikTok URL without releasing the app again, edit:

```text
src/pages/password-game/tiktok.astro
```

Change:

```astro
const tikTokUrl = "https://www.tiktok.com/@werewolf_undercover_app";
```

Then deploy the site with the normal deploy steps above.

Do not edit `dist` manually. It is generated by `npm run build`.
